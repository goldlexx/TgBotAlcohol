# НЕ ПЬЮ | Счастье без алкоголя

Закрытая тестовая версия Telegram-бота на Cloudflare Workers, D1 и Cron. Дни без алкоголя, личный прогресс и идеи для жизни без спиртного. Бесплатно, без рекламы. Тестовый контур предназначен для синтетических данных.

## Интерфейс v2.4.4

В v2.4.4 добавлен транзакционный `delivery_outbox` (`migrations/0003_delivery_outbox.sql`) для повторной доставки ответов webhook без дубликатов, возврат к шагам `check` / `background` / `paused` из `n:emergency` и `n:care.help` через `n:resume`, а также сохранение выбранных дней недели при редактировании календарного бюджета «За привычный день».

## Интерфейс v2.4.3

Cron восстанавливает отсутствующие задания подписанных пользователей с активной серией. Выбирается ближайший будущий слот по сохранённому расписанию.

В v2.4 и v2.4.1 обновлены ключевые пользовательские сценарии по итогам ручной приёмки:
- **Восстановление:** двухуровневая подача без перегрузки научными оговорками на основном экране; компактный ближайший ориентир без дубля шкалы; содержательная 6-этапная шкала с описаниями, пагинацией (`Страница X из 2`) и карточками подробностей по каждому этапу. [Текстовые примеры](docs/recovery-examples.txt)
- Медицинские флаги сохраняются и задают сдержанный формат автоотчёта. Обычные настройки и расписание доступны. «Мне плохо» открывает помощь без изменения подписки.
- **Уведомления и настройки:** статус подписки, время и состояние расписания показаны отдельно; «Пример уведомления» заменил «Превью»; добавлена кнопка «К уведомлениям» после сохранения времени; сводка настроек разделена на смысловые блоки.
- **Прогресс, отчёт, статистика, история:** убрано дублирование эмодзи напитка, кнопка утреннего отчёта переименована в «Восстановление», обновлены формулировки подробной статистики и каталога идей, добавлены продолжительность серий и пустое состояние истории.

Повторный `/start` восстанавливает постоянное меню. `/cancel` сбрасывает текущий ввод и возвращает к меню или приветствию. Медицинский выход возвращает к прогрессу или приветствию. В подробной статистике можно уточнить тип напитка в старой записи. В истории можно отменить удаление ошибочного эпизода или подтвердить его после просмотра. `/morning` открывает полный отчёт, а личная цель отмечается в день достижения. Обычный утренний отчёт унифицирован с «НЕ КУРЮ» (заголовок, шкала, показатели, факт о здоровье, `💡 Мысль дня`, кнопки `[Восстановление] [Мой прогресс]`, `[Подробнее и источники]`, `[ℹ️ Как считаем]`) и при активных медицинских флагах подбирает безопасные нейтральные факты и спокойные поддерживающие мысли без тревожного баннера. В каталоге 200 идей, 60 советов при тяге, 12 достижений и 45 фактов о здоровье. Каталог разделён на восстановление, общие факты и риски. На обычных экранах нет черновиков, а ссылки вынесены в «Методику и источники». Для редакторского просмотра используй `node scripts/preview-facts.mjs`. Для пива без сведений об упаковке показан общий объём.

Активные медицинские тексты подчинены единому редакционному стандарту (`docs/clinical-review.md`): без вводных оговорок «может / возможно / обычно / в среднем / у некоторых людей», через доказанную пользу отказа и с корректными названиями периодов (`1–3 месяца` для 30–90 дней). Публичное меню Telegram использует единый порядок команд (`/start`, `/morning`, `/cancel`), а `/admin` остаётся скрытой командой владельца.

После регистрации бот показывает прогресс и предлагает выбрать время ежедневного отчёта. Пресет или корректно введённое время сохраняются сразу. В настройках время меняется отдельно от частоты и подключения. Экран уведомлений показывает ближайшую запланированную отправку или причину паузы.

Старые профили читаются без миграции схемы. Если дни прежней еженедельной рассылки неизвестны, бот ждёт выбора пользователя. Медицинская пауза сохраняет ручной отчёт, статистику и историю.

Владелец отправляет `/admin` в личном чате с ботом. Команда доступна только по числовому Telegram ID владельца и выводит агрегаты без изменений в базе. В текущем закрытом контуре владелец — единственный чат из закрытого списка доступа. Для отдельной настройки владельца используется секрет `OWNER_CHAT_ID`.

## Локальная проверка

Нужен Node.js 24 с npm. В Windows можно использовать `npm.cmd` и `npx.cmd`.

```powershell
npm.cmd ci
npm.cmd test
npx.cmd wrangler d1 migrations apply DB --local
npm.cmd run dev
```

Локальные адреса `GET /health` и `GET /__scheduled` проверяют запуск Worker и обработчик Cron. `POST /telegram/webhook` принимает личные Telegram-обновления только при совпадении webhook secret и ID из allowlist. Без секретов обработчик отклоняет обновления, а Cron пропускает отправку. Имена переменных перечислены в `.env.example`. Wrangler читает локальные значения из игнорируемого `.dev.vars`.

`npm test` поднимает временную D1 в Miniflare и подменяет отправку в Telegram. Нагрузочный сценарий ставит 200 синтетическим профилям один слот, вызывает конкурирующие Cron и запускает 20 параллельных обновлений. Включены обычные и нейтральные отчёты. Время выполнения печатается в выводе теста. Это локальный замер, облачная задержка и запас CPU требуют отдельного прогона.

## Код

- `src/worker.js`, `src/telegram.js` — webhook, команды, допуск по ID и Bot API.
- `src/dialogs.js`, `src/views.js`, `src/safety.js` — состояние диалога, экраны и медицинский маршрут.
- `src/time.js`, `src/calculations.js`, `src/history.js`, `src/habits.js` — часовые пояса, серии, оценки и история.
- `src/storage.js`, `src/scheduler.js`, `migrations/` — транзакции D1, задания и учёт попыток доставки.
- `content/` — каталог идей и фактов с источниками и статусом клинической редакции.

Публичный запуск требует отдельного решения владельца после клинической проверки текстов и правовой проверки обработки данных.
