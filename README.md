# Счастье без алкоголя

Закрытая тестовая версия Telegram-бота на Cloudflare Workers, D1 и Cron. Дни без алкоголя, личный прогресс и идеи для жизни без спиртного. Бесплатно, без рекламы. Тестовый контур предназначен для синтетических данных.

## Интерфейс v2.2

Повторный `/start` восстанавливает постоянное меню и открывает прогресс со всеми действиями. `/morning` открывает полный ручной отчёт с выбранными показателями, рубежом, фактом и идеей. В настройках уведомлений «Превью» показывает формат автоматической отправки. Переключение формата не меняет медицинские ограничения. В каталоге 120 жизненных идей, 60 советов при тяге и 12 достижений.

v2.2 читает старые профили с `trackingPaused` без отдельной миграции схемы. Медицинская пауза применяется к автоматическим уведомлениям. Ручной отчёт, статистика и история остаются доступны. Для закрытого Worker используется игнорируемая локальная конфигурация.

## Локальная проверка

Нужен Node.js 24 с npm. В Windows можно использовать `npm.cmd` и `npx.cmd`.

```powershell
npm.cmd ci
npm.cmd test
npx.cmd wrangler d1 migrations apply DB --local
npm.cmd run dev
```

Локальные адреса `GET /health` и `GET /__scheduled` проверяют запуск Worker и обработчик Cron. `POST /telegram/webhook` принимает личные Telegram-обновления только при совпадении webhook secret и ID из allowlist. Без секретов обработчик отклоняет обновления, а Cron пропускает отправку. Имена переменных перечислены в `.env.example`. Wrangler читает локальные значения из игнорируемого `.dev.vars`.

`npm test` поднимает временную D1 в Miniflare и подменяет отправку в Telegram. Нагрузочный сценарий ставит 200 синтетическим профилям один слот, вызывает конкурирующие Cron и запускает 20 параллельных обновлений. Включены обычные и нейтральные отчёты. Время выполнения печатается в выводе теста. Это локальный замер, облачная задержка и запас CPU требуют отдельного прогона.

## Код

- `src/worker.js`, `src/telegram.js` — webhook, команды, допуск по ID и Bot API.
- `src/dialogs.js`, `src/views.js`, `src/safety.js` — состояние диалога, экраны и медицинский маршрут.
- `src/time.js`, `src/calculations.js`, `src/history.js`, `src/habits.js` — часовые пояса, серии, оценки и история.
- `src/storage.js`, `src/scheduler.js`, `migrations/` — транзакции D1, задания и учёт попыток доставки.
- `content/` — каталог идей и фактов с источниками и статусом клинической редакции.

Публичный запуск требует отдельного решения владельца после клинической проверки текстов и правовой проверки обработки данных.
